# お店紹介記事の制作ルール

利用者が2026年10月30日に指定した、お店紹介記事の標準です。
このディレクトリでチャッピーが新しく作成・編集するお店紹介、いろは47士列伝などの紹介記事に適用してください。

## 基本の並び
1. 記事タイトル。
2. 動画（動画がなければ紹介画像）。
3. 動画・画像のすぐ下に、紹介する店名を大きく表示した紹介枠。
4. 店の魅力を伝える短い紹介文。
5. 店の紹介ページ・場所へ進める、分かりやすいボタン。
6. 必要最小限の出典・制作表記と共有欄。

## 動画の再生
- 動画は controls loop playsinline を付け、再生終了後は先頭に戻って繰り返す。
- 最初の再生は利用者が操作し、一時停止ボタンで止められるようにする。

## 表示のルール
- 動画と店名の間に「本日の物語」、会話の書き起こし、長い企画説明、あいさつを挟まない。
- 動画の内容を文章で繰り返さず、すぐに店の紹介へ進める。
- 店名は本文から明確に区別する。太い角ゴシック、大きな紫色の文字、金色の枠、淡い背景を使う。
- 参照実装は fujiko-news.html の #iroha47 .featured-shop と #featured-shop-name。店名はスマートフォンの幅に合わせて自然に改行する。
- 紹介文は短く、事実に基づいて記載する。営業・価格・特典などを作り上げない。
- 店の紹介・場所への導線と既存のSNS共有機能を維持する。
- スマートフォンで横にはみ出さず、店名とボタンが見つかりやすいことを確認する。

## 作業の進め方
- 記事作成・画面編集・検証・公開反映はチャッピーが担当する。利用者にHTML編集や貼り替えを前提とした手順を渡さない。
- 編集前に必ず最新のソースと現在の公開内容を確認し、ほかの作業による更新を上書きしない。
- このルールはチャッピーが制作するお店紹介記事の既定値。店舗情報ページ、利用案内、店主が投稿した本文を機械的に削除・変更しない。
- 各記事の内容や対象店舗が未指定の場合、架空の記事や未確認のキャンペーンを勝手に公開しない。
- 公開後に、動画・画像のすぐ下に店名が出ること、店へのリンクが正しいことを確認して報告する。


## 導線の固定ルール（2026-11-18 / v1）
- 共通導線は dx-nav.js / dx-nav.css に集約する。画面下は「トップ／お店を探す／投稿を見る／お得情報」の4つ。上部は「お店一覧／投稿・編集」。名前・順番・紫系の既存色を勝手に変えない。
- 店舗・活動ページには body.social-profile、#intro、#photos、#information、#share を置く。#intro h1 に店名を記載する。共通スクリプトは未登録の店舗もこの構造から認識する。
- #intro の短い紹介の次にページ内メニューを置く。写真・情報・共有へ直接進めること。実在しない欄へのリンクは禁止。
- 記事には一覧へ戻る入口と対象店舗への入口を維持する。外部SNSは別画面、DX内は同じ画面。ブラウザ履歴だけに依存した戻るボタンは禁止。
- 共有は「ハートネット志木」「ふじこ」の両方、紹介文の切替・コピー・LINE・Facebook・Xを維持。名義の公開範囲・ログイン判定も勝手に変更しない。主要ボタンは既存の紫地・白文字、SNS固有の色も維持。
- 新規店舗は一意のIDと固定URLで追加。index.html の sample・shopPages に追加し、既存sampleの並びを変更しない。既存sample[0]等に依存する処理を壊さない。
- 店主用の登録がない店にSHOP番号を勝手に付けない。店舗の正式登録・投稿機能の接続は別途実データを確認する。
- shops.json と記事側の店舗URL対応（posts.js）も必要性を確認する。GAS・API・JSONP・DB列・既存共有URLは導線変更のついでに作り直さない。
- 新しいページも共通CSS/JSの同じバージョンを読む。共通部品変更時は参加ページのURLバージョンを同時更新する。
- ページ追加後は「トップ→店舗→写真/情報/共有→一覧」「投稿一覧→記事→対象店舗」「お得情報→詳細→店舗」「投稿・編集→公開画面」を点検し、375px程度の幅・横はみ出し・固定メニューとの重なりを確認する。
- 紹介の重複一覧をトップ下部へ再追加しない。写真・動画・記事・特典・店主の入力・検索/戻り位置の復元を維持する。
- 設計の詳細と追加手順は docs/omise-dx-navigation-design.md および利用者に渡したPDFを参照。現在の試行対象は、おうちcafeパン工房・ハートネット志木・ニュータイムス社の3店舗。追加時はそのページも往復で実機確認する。
