# お店紹介記事の制作ルール

利用者が2026年10月30日に指定した、お店紹介記事の標準です。
このディレクトリでチャッピーが新しく作成・編集するお店紹介、いろは47士列伝などの紹介記事に適用してください。

## 基本の並び
1. 記事タイトル。
2. 動画（動画がなければ紹介画像）。
3. 動画・画像のすぐ下に、紹介する店名を大きく表示した紹介枠。
4. 店の魅力を伝える短い紹介文。
5. 店の紹介ページ・場所へ進める、分かりやすいボタン。
6. 必要最小限の出典・制作表記と共有欄。

## 表示のルール
- 動画と店名の間に「本日の物語」、会話の書き起こし、長い企画説明、あいさつを挟まない。
- 動画の内容を文章で繰り返さず、すぐに店の紹介へ進める。
- 店名は本文から明確に区別する。太い角ゴシック、大きな紫色の文字、金色の枠、淡い背景を使う。
- 参照実装は fujiko-news.html の #iroha47 .featured-shop と #featured-shop-name。店名はスマートフォンの幅に合わせて自然に改行する。
- 紹介文は短く、事実に基づいて記載する。営業・価格・特典などを作り上げない。
- 店の紹介・場所への導線と既存のSNS共有機能を維持する。
- スマートフォンで横にはみ出さず、店名とボタンが見つかりやすいことを確認する。

## 作業の進め方
- 記事作成・画面編集・検証・公開反映はチャッピーが担当する。利用者にHTML編集や貼り替えを前提とした手順を渡さない。
- 編集前に必ず最新のソースと現在の公開内容を確認し、ほかの作業による更新を上書きしない。
- このルールはチャッピーが制作するお店紹介記事の既定値。店舗情報ページ、利用案内、店主が投稿した本文を機械的に削除・変更しない。
- 各記事の内容や対象店舗が未指定の場合、架空の記事や未確認のキャンペーンを勝手に公開しない。
- 公開後に、動画・画像のすぐ下に店名が出ること、店へのリンクが正しいことを確認して報告する。
